# Arka website recording output

Generated by Arka browser stack (`browser_check`, `web_screenshot`, `automate`) and Playwright video capture.

- `browser-check.png` — smoke check screenshot
- `website-{pc,tablet,mobile}.png` — responsive viewport captures
- `session/` — step-by-step automation screenshots
- `session-recording.mp4` — full UI walkthrough video (Playwright record)
- `video/` — raw WebM from Playwright
- `video-frames/` — screenshots + extracted video frames
- `video-report.json` — console errors captured during recording
- `automation-steps.json` — reusable Playwright test plan
- `record_session.py` — record video + replay automation steps

Run again:

```bash
URL=http://localhost:5174
arka browser_check "$URL" --output recordings/browser-check.png --json
arka automate "$URL" --steps recordings/automation-steps.json --output recordings/session --json
python recordings/record_session.py
```
